# Türkiye Tıp Kütüphaneciliği AHP Uzman Değerlendirme Formu

Uzmanların 4 ana alan, 9 tema ve 21 temel yetkinlik için 27 ikili karşılaştırmayı doldurduğu web formu.

## Canlı form

[AHP Uzman Değerlendirme Formunu aç](https://ffgebel.github.io/turkiye-tip-kutuphaneciligi-ahp-uzman-formu/)

Uzmanlar bağlantıyı açarak formu tarayıcıda doldurabilir. Form tamamlandığında JSON, CSV veya PDF çıktısı alınabilir.
